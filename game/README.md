# Арена Менеджер (рабочее название)

Оригинальная игра-менеджер киберспортивной команды: собираете состав из 5 игроков,
тренируете их, выбираете чемпионов на драфте и смотрите авто-матч 5 на 5.
Игра своя: имена, чемпионы, графика и правила придуманы с нуля.

## Что уже есть (прототип 0.1)
- Лига из 6 команд, круговой турнир на 10 недель, таблица.
- Неделя: тренировка (атака / защита / тактика / отдых) → драфт → матч → итог.
- 12 оригинальных чемпионов в 6 ролях, у каждого своя способность.
- Матч 2 минуты: побеждает тот, кто разрушил ядро или сделал больше убийств.
- Скорость 1×/2×/4× и мгновенный итог. Статы игроков влияют на бой.
- Бюджет: призовые и зарплаты. Автосохранение в браузере.
- Отрисовка Canvas 2D, не больше 30 кадров/с, чтобы телефон не грелся.
  В портретном режиме поле поворачивается вертикально.

## Запуск
```
npm install
npm run dev     # открыть адрес из консоли, в том числе с телефона в той же сети
npm run build   # готовая веб-версия в dist/
```
